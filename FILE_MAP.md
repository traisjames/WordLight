# WordLight — File Structure Map

Where every file belongs on the server. Use this when copying updated
files across, since files are often delivered in a flat list but most of
the web pages actually live inside `public/`.

---

## The complete structure

```
wordlight/                          ← project root (e.g. /home/wordlight/CC_Server)
│
├── server.js                       ← main server
├── ecosystem.config.js             ← pm2 config for both processes
├── package.json                    ← npm dependencies
├── package-lock.json               ← auto-generated by npm install
├── .env                            ← YOUR config — never share, never commit
├── env.example                     ← template to copy from
├── README.md                       ← main documentation
├── PM2_MONITORING.md               ← pm2.io dashboard guide
├── GETTING_STARTED.md              ← beginner setup guide (not yet written)
├── FILE_MAP.md                     ← this file
├── oled_display.py                 ← OLED screen + buttons (Raspberry Pi only)
├── monitor.sh                      ← load-test monitoring helper (pidstat + lsof)
├── .gitignore                      ← keeps .env and certs/ out of git
│
├── certs/                          ← AUTO-GENERATED on first run — do not create by hand
│   ├── cert.pem
│   ├── key.pem                     ← private key — never share or commit
│   └── cert-meta.json              ← tracks which IPs the cert covers
│
├── node_modules/                   ← AUTO-GENERATED by npm install — never copy by hand
│
├── setup/                          ← first-time installation helpers
│   ├── setup.sh                    ← the installer (chmod +x)
│   ├── smb.conf.template           ← Samba share config
│   ├── motd.template               ← login message, full version
│   ├── motd-simple.template        ← login message, stats only
│   └── power_report                ← throttle/temperature check (chmod +x)
│
├── load-test/                      ← stress-testing tool — runs on your Mac, NOT the Pi
│   ├── load_test.js
│   ├── package.json                ← separate deps; keeps socket.io-client off the server
│   └── README.md
│
└── public/                         ← everything the browser can reach
    ├── global.js                   ← shared JS + THEATER_NAME
    ├── styles.css                  ← shared styles + OpenDyslexic @font-face
    ├── home.html                   ← landing page + QR code
    ├── login.html                  ← admin login
    ├── controller.html             ← operator's script navigator
    ├── editor.html                 ← script editor
    ├── reader.html                 ← audience captions
    ├── backstage.html              ← actor monitor with notes
    ├── preferences.html            ← reader display settings
    ├── logging.html                ← usage statistics
    ├── help.html                   ← conventions + shortcuts
    ├── favicon.png                 ← YOUR theater's icon
    ├── iconlarge.png               ← YOUR theater's logo
    └── fonts/
        ├── OpenDyslexic-Regular.woff2
        ├── OpenDyslexic-Bold.woff2
        ├── OpenDyslexic-Italic.woff2
        ├── OpenDyslexic-BoldItalic.woff2
        └── OFL.txt                  ← license — must stay with the fonts
```

Outside the project folder:

```
/home/wordlight/
├── CC_Server/                      ← the project root above
├── Scripts/                        ← show scripts (Samba share, group: scriptusers)
└── power_report                    ← optional copy, installed by setup.sh
```

## ⚠️ The easy mistake

Most `.html` files, plus `global.js` and `styles.css`, are delivered as a
flat list — but they belong in **`public/`**, not the project root.

Only these belong at the root:

| At the root | Inside `public/` |
|---|---|
| `server.js` | every `.html` file |
| `ecosystem.config.js` | `global.js` |
| `package.json` | `styles.css` |
| `oled_display.py` | `favicon.png`, `iconlarge.png` |
| `monitor.sh` | `fonts/` |
| `*.md` documentation | |

If a page loads but looks completely unstyled, `styles.css` probably
landed at the root instead of in `public/`.

## Files that are yours, not mine

These I've either never modified or can't produce — don't overwrite them
with anything from a delivered file list:

- **`.env`** — your real configuration, including passwords
- **`public/favicon.png`** and **`public/iconlarge.png`** — your theater's branding
- **`public/login.html`** — unchanged since early in the project
- **`Scripts/`** — your show scripts
- **`certs/`** — generated automatically on first run

---

## Auto-generated — never copy by hand

- **`node_modules/`** — run `npm install` instead
- **`package-lock.json`** — npm maintains it
- **`certs/`** — `server.js` creates it, and regenerates it if the Pi's IP changes

---

## After copying files across

```bash
# If package.json changed
npm install

# Make scripts executable (this is lost when copying between machines)
chmod +x setup/setup.sh setup/power_report monitor.sh

# Restart to pick up changes
pm2 restart wordlight

# Only needed if oled_display.py changed
pm2 restart oled-display
```

`.env` changes only take effect after a restart — editing the file alone
does nothing until `pm2 restart wordlight`.
