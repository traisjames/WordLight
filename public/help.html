📋 Script Conventions

SyntaxEffect
[red]NAME:[/] Colored character name. Available colors:
[red] [orange] [yellow] [green] [cyan] [blue] [purple] [pink] [gray] [grey] [white]
e.g. [orange]NEMO:[/] Dad! ~ [red]MARLIN:[/] You get tired.
[b]text[/] Bold text
[i]text[/] Italic text
[u]text[/] Underlined text
♫ text ♫ Music or song cue indicator
e.g. ♫ BIG BLUE WORLD ♫
~ Wide gap (two em spaces) — separates speakers on one caption line
e.g. [orange]NEMO:[/] Dad! ~ [red]MARLIN:[/] You get tired.
⏎ Inline line break — displays two lines of text at the same time in a single caption step
e.g. [orange]NEMO:[/] I can! ⏎ [red]MARLIN:[/] No you can't!
caption text|note Speaker note — everything after | is visible only on the Controller and Backstage screens, never to the audience
e.g. Welcome to the show.|Pause for applause
| Page 5 Blank reader line with a page marker note — audience sees nothing, Controller and Backstage show the page number
| Silent moment — blanks the audience display during pauses or scene changes

🎛 OSC Commands

Admin only
Protocol: UDP · Open Sound Control    Default port: 8000    Target IP: your Pi's IP address
All addresses are case-insensitive. Line numbers are 1-based matching the numbers shown in the Controller and Editor.
OSC AddressAction
/CC/next Advance to the next line
/CC/prev Go back one line
/CC/first Jump to line 1
/CC/last Jump to the last line
/CC/line/37 Jump to a specific line number (1-based)
e.g. /CC/line/1 · /CC/line/42 · /CC/Line/100
/CC/intermission Show the "Please Stand By" intermission overlay on all reader screens
/CC/resume Hide the intermission overlay and return to captions
/CC/armed Alert controllers that OSC is taking control — turns the controller interface green
/CC/disarmed Return the controller interface to its normal appearance
